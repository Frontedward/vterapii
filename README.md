# VTerapii - Платформа для онлайн-консультаций с врачами

## Описание
VTerapii - это современная веб-платформа, разработанная для проведения онлайн-консультаций между пациентами и врачами. Платформа предоставляет удобный интерфейс для записи на прием, проведения видеоконсультаций и обмена сообщениями.

## Технологии
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- WebSocket для чата
- Progressive Web App (PWA)

## Требования
- Node.js 18.0 или выше
- npm или yarn
- Современный веб-браузер с поддержкой WebRTC

## Установка и запуск

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Frontedward/vterapii.git
cd vterapii
```

2. Установите зависимости:
```bash
npm install
# или
yarn install
```

3. Создайте файл `.env.local` в корневой директории проекта и добавьте необходимые переменные окружения:
```env
NEXT_PUBLIC_API_URL=http://localhost:3000/api
```

4. Запустите проект в режиме разработки:
```bash
npm run dev
# или
yarn dev
```

5. Откройте [http://localhost:3000](http://localhost:3000) в браузере.

## Структура проекта

```
src/
├── app/              # Страницы приложения (Next.js App Router)
├── components/       # React компоненты
├── hooks/           # Пользовательские React хуки
├── lib/             # Вспомогательные функции
├── services/        # Сервисы для работы с API
├── types/           # TypeScript типы
└── utils/           # Утилиты

public/
├── icons/           # Иконки для PWA
└── manifest.json    # Манифест PWA
```

## Основные функции

### Для пациентов
- Регистрация и авторизация
- Поиск врачей по специализации
- Запись на консультацию
- Онлайн-консультации через видеосвязь
- Чат с врачом
- История консультаций

### Для врачей
- Профессиональный профиль
- Управление расписанием
- Проведение онлайн-консультаций
- Ведение истории пациентов
- Чат с пациентами

## Сборка для продакшена

```bash
npm run build
npm start
# или

```

## PWA
Приложение поддерживает установку как Progressive Web App (PWA), что позволяет использовать его на мобильных устройствах с почти нативным опытом.
